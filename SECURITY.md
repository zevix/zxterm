# Security policy

`zxterm-core` handles SSH keys, identity keys and session encryption for ZBTerm, so security
reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/zevix/zxterm/security/advisories/new) for this
repository.

Include what you found, how to reproduce it, the version (`zxterm-core --version`) and your
platform. We aim to acknowledge reports within a few days and will keep you updated until a fix
is released.

A vulnerability that is only reachable through the ZBTerm app can be reported in either
repository.

## Supported versions

Only the latest published `zxterm-core-prebuilds` release receives security fixes.
